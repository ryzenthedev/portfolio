This project is a modern personal portfolio website built with React and Tailwind CSS. It showcases a refreshed UI, a responsive layout, language support for Turkish and English, project cards, a contact form, and a polished landing experience.

## Features

- Fully redesigned personal website interface
- Responsive navigation and mobile-friendly menu
- Turkish / English language support
- Custom hero section, project gallery, about page, contact form
- Hidden metadata and identifiers for project tracking
- Production-ready build with React scripts

## Installation

```bash
npm install
```

## Development

```bash
npm start
```

Open `http://localhost:3000` to view the site locally.

## Build

```bash
npm run build
```
